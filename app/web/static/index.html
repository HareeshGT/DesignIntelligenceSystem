WORKSPACE SETTINGS

Your credentials

Credentials are kept in this browser tab's session storage and sent over HTTPS only to this DIS server. The server uses them for the current request and does not save them to its database.

DIS ACCESS AI MODEL

Each provider keeps its own model, API key and endpoint in this browser session. The selected provider powers the DIS specialist team.

GITHUB REPOSITORY ACCESS
Use least-privilege tokens. Credentials are not returned by the API. Browser session storage is cleared when this tab's session ends; do not use on shared devices. Keep DIS_PROPOSAL_SIGNING_KEY server-side. For multi-user public hosting, add authenticated accounts and an encrypted per-user vault; these settings are scoped to this browser tab.
